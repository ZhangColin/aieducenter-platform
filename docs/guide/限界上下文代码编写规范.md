# 限界上下文代码编写规范

> **版本**：v2.0 | **日期**：2026-04-02
> **参考模板**：Admin Context (`com.aieducenter.admin`)

本文档定义了基于 cartisan-boot 框架的限界上下文（Bounded Context）代码编写规范，确保团队代码风格统一、架构清晰。

---

## 一、包结构规范

### 1.1 标准包结构

每个限界上下文采用 DDD 六边形架构，包结构如下：

```
com.aieducenter.{context}
├── package-info.java           # 上下文说明（JavaDoc）
├── domain/                     # 领域层
│   ├── aggregate/              # 聚合根
│   ├── entity/                 # 实体
│   ├── repository/             # 仓储接口
│   ├── service/                # 领域服务（按需创建）
│   ├── error/                  # 领域错误定义（CodeMessage 枚举）
│   └── model/                  # 值对象、领域枚举
├── application/                # 应用层
│   ├── dto/                    # 数据传输对象
│   │   ├── command/            # 命令 DTO（写操作）
│   │   ├── query/              # 查询 DTO（读操作）
│   │   └── response/           # 响应 DTO
│   ├── mapper/                 # 领域对象与 DTO 转换器
│   └── {Xxx}AppService.java    # 应用服务
└── web/                        # 表现层
    └── controller/             # REST 控制器
```

### 1.2 package-info.java 模板

每个上下文根包必须有 `package-info.java` 说明文件：

```java
/**
 * {Context Name} Context。
 *
 * <h3>职责</h3>
 * <ul>
 *   <li>{核心职责1}</li>
 *   <li>{核心职责2}</li>
 * </ul>
 *
 * <h3>限界上下文</h3>
 * <p>{上下文边界说明}</p>
 *
 * <h3>包结构</h3>
 * <ul>
 *   <li>domain - 领域层：聚合根、实体、仓储接口、领域服务</li>
 *   <li>application - 应用层：应用服务、DTO</li>
 *   <li>web - 表现层：控制器</li>
 * </ul>
 *
 * @since 0.1.0
 */
package com.aieducenter.{context};
```

## 二、领域层规范

### 2.1 聚合根（Aggregate）

**位置**：`domain/aggregate`

**命名规范**：`{Entity}.java`（无需后缀）

**核心规范**：

```java
@Entity
@Table(name = "{prefix}_{table_name}")
@Aggregate
public class AdminUser extends AuditableSoftDeletable implements AggregateRoot<AdminUser> {

    // ✅ v2.0 正确示例：领域层不应直接依赖外部框架
    // 应通过领域服务封装，使用 PasswordEncoderService
    // 错误示例：private static final BCryptPasswordEncoder PASSWORD_ENCODER = new BCryptPasswordEncoder(10);
    // 正确做法：通过 @DomainService 封装 PasswordEncoderPort
    // 参考：com.aieducenter.admin.domain.service.PasswordEncoderService

    // ========== 字段声明 ==========

    @Getter
    @Id
    @Column(name = "id", nullable = false, updatable = false)
    private Long id;

    @Getter
    @Column(name = "username", nullable = false, unique = true, length = 50)
    private String username;

    @Column(name = "email", length = 255)
    private String email;

    // ========== 构造函数 ==========

    /**
     * 创建聚合根。
     *
     * @param username 用户名（必填）
     * @param plainPassword 明文密码
     * @param nickname 昵称
     */
    public AdminUser(String username, String plainPassword, String nickname) {
        // 参数校验
        validateUsername(username);
        validatePasswordStrength(plainPassword);

        this.username = username;
        this.password = PASSWORD_ENCODER.encode(plainPassword);
        this.nickname = nickname != null && !nickname.isBlank() ? nickname : username;
        this.status = AdminStatus.ACTIVE;
    }

    /**
     * JPA 默认构造函数。
     */
    protected AdminUser() {
    }

    /**
     * JPA 保存前生成 ID。
     */
    @PrePersist
    void prePersist() {
        if (id == null) {
            this.id = TsidGenerator.newInstance().generate();
        }
    }

    // ========== Getter/Setter ==========

    // 简单 getter 使用 @Getter 注解
    // 需要 Optional 包装的 getter 手写
    public Optional<String> getEmail() {
        return Optional.ofNullable(email);
    }

    // 简单 setter 使用 @Setter 注解
    // 有业务逻辑的 setter 手写
    public void setType(MenuType type) {
        this.type = type != null ? type : MenuType.MENU;
    }

    // ========== 业务行为 ==========

    /**
     * 验证密码。
     */
    public boolean matchesPassword(String plainPassword) {
        return PASSWORD_ENCODER.matches(plainPassword, this.password);
    }

    /**
     * 修改密码。
     */
    public void updatePassword(String oldPassword, String newPassword) {
        Assertions.require(matchesPassword(oldPassword), AdminMessage.PASSWORD_INCORRECT);
        validatePasswordStrength(newPassword);
        this.password = PASSWORD_ENCODER.encode(newPassword);
    }

    // ========== 私有方法 ==========

    private void validateUsername(String username) {
        if (username == null || !username.matches(USERNAME_PATTERN)) {
            throw new DomainException(AdminMessage.USERNAME_INVALID);
        }
    }
}
```

**聚合根规范要点**：

1. 继承 `AuditableSoftDeletable`（自动提供审计字段 + 软删除）
2. 实现 `AggregateRoot<T>` 接口
3. 使用 `@Aggregate` 注解标记
4. 简单字段使用 `@Getter`/`@Setter` 注解（字段级）
5. 有业务逻辑的方法手写（含 getter/setter）
6. 构造函数负责不变量校验
7. `@PrePersist` 生成 TSID

### 2.4 领域错误定义

**位置**：`domain/error`

**命名规范**：`{Context}Message.java`

```java
/**
 * Admin 模块消息定义。
 *
 * <h3>消息分类</h3>
 * <ul>
 *   <li>格式校验错误 (400): USERNAME_INVALID, PASSWORD_WEAK</li>
 *   <li>唯一性错误 (409): USERNAME_ALREADY_EXISTS</li>
 *   <li>资源不存在 (404): ADMIN_NOT_FOUND</li>
 *   <li>业务限制 (403): LAST_ADMIN_CANNOT_DELETE</li>
 * </ul>
 */
public enum AdminMessage implements CodeMessage {

    // ========== 格式校验错误 (400) ==========

    USERNAME_INVALID(400, "ADMIN_001", "用户名格式不正确"),
    PASSWORD_WEAK(400, "ADMIN_002", "密码强度不足"),

    // ========== 唯一性错误 (409) ==========

    USERNAME_ALREADY_EXISTS(409, "ADMIN_003", "用户名已存在"),

    // ========== 资源不存在 (404) ==========

    ADMIN_NOT_FOUND(404, "ADMIN_006", "管理员不存在"),

    // ========== 业务限制 (403) ==========

    LAST_ADMIN_CANNOT_DELETE(403, "ADMIN_012", "不能删除最后一个管理员");

    private final int httpStatus;
    private final String code;
    private final String message;

    AdminMessage(int httpStatus, String code, String message) {
        this.httpStatus = httpStatus;
        this.code = code;
        this.message = message;
    }

    @Override
    public int httpStatus() {
        return httpStatus;
    }

    @Override
    public String code() {
        return code;
    }

    @Override
    public String message() {
        return message;
    }
}
```

**错误码规范**：`{CONTEXT}_{NUMBER}`，如 `ADMIN_001`

### 2.5 领域服务（DomainService）

**位置**：`domain/service`

**命名规范**：`{Scenario}Service.java` 或 `{DomainConcept}Service.java`

> **注意**：按场景命名，而非按模块。例如 `RolePermissionService`（角色权限相关）、`MenuTreeService`（菜单树构建）。

**何时使用**：
- 涉及多个聚合根的复杂领域逻辑
- 不属于任何单一聚合根的业务规则
- 需要被多个 AppService 复用的逻辑

**架构原则**：DomainService 不涉及 DTO

| 返回类型 | 说明 |
|---------|------|
| 领域模型（聚合根/实体） | ✅ 可以返回 |
| 基本类型（Long/void/boolean） | ✅ 可以返回 |
| DTO | ❌ 禁止涉及 |

```java
@DomainService
public class RolePermissionService {

    private final AdminRoleRepository roleRepository;
    private final PermissionScanner permissionScanner;

    public RolePermissionService(AdminRoleRepository roleRepository,
                                 PermissionScanner permissionScanner) {
        this.roleRepository = roleRepository;
        this.permissionScanner = permissionScanner;
    }

    /**
     * 验证权限码是否有效。
     *
     * @param permissionCodes 待验证的权限码
     * @return 无效的权限码列表
     */
    public List<String> validatePermissionCodes(Set<String> permissionCodes) {
        Set<String> validCodes = permissionScanner.scanByScope("admin").stream()
                .map(Permission::code)
                .collect(Collectors.toSet());

        return permissionCodes.stream()
                .filter(code -> !validCodes.contains(code))
                .toList();
    }

    /**
     * 检查角色是否拥有指定权限。
     */
    public boolean hasPermission(Long roleId, String permissionCode) {
        return roleRepository.findById(roleId)
                .map(role -> role.getPermissionCodes().contains(permissionCode))
                .orElse(false);
    }
}
```

**领域服务规范要点**：

1. 使用 `@DomainService` 注解
2. 构造函数注入
3. 不涉及 DTO 转换
4. 可以返回领域模型
5. 可以被 AppService 调用

### 2.6 枚举和常量规范

**原则**：枚举和常量在领域层定义，外部通过字符串交互。

#### 2.6.1 枚举定义

枚举定义在聚合根或实体内部，提供 `fromString()` 静态方法：

```java
public class AdminUser extends AuditableSoftDeletable implements AggregateRoot<AdminUser> {

    /**
     * 管理员状态枚举。
     */
    public enum AdminStatus {
        ACTIVE,
        DISABLED;

        /**
         * 从字符串解析状态。
         */
        public static AdminStatus fromString(String status) {
            if (status == null) {
                throw new IllegalArgumentException("Status cannot be null");
            }
            return valueOf(status);
        }
    }
}
```

#### 2.6.2 常量定义

常量在聚合根中定义为 `public static final`：

```java
@Aggregate
public class AdminRole extends AuditableSoftDeletable implements AggregateRoot<AdminRole> {

    /**
     * 超级管理员角色码。
     */
    public static final String SUPER_ADMIN_CODE = "SUPER_ADMIN";

    /**
     * 是否为超级管理员角色。
     */
    public boolean isSuperAdmin() {
        return SUPER_ADMIN_CODE.equals(this.code);
    }
}
```

#### 2.6.3 架构边界规则

| 层级 | 处理方式 |
|------|---------|
| **Controller** | 接收/返回 String，不导入领域枚举 |
| **AppService** | 调用领域 `fromString()` 解析 |
| **Domain** | 定义枚举和解析方法 |

```java
// Controller - 不导入领域枚举
public void updateStatus(@PathVariable Long id, @RequestParam String status) {
    adminManagementAppService.updateStatus(id, status);
}

// AppService - 调用领域方法解析
@Transactional
public void updateStatus(Long id, String status) {
    AdminUser adminUser = adminUserRepository.findById(id).orElseThrow();
    AdminUser.AdminStatus statusEnum = AdminUser.AdminStatus.fromString(status);
    // ...
}

// Domain - 定义解析方法
public enum AdminStatus {
    ACTIVE,
    DISABLED;

    public static AdminStatus fromString(String status) { /* ... */ }
}
```

**禁止**：Controller 导入 `import ...domain.aggregate.AdminUser;`

### 2.7 领域层解耦规范

**核心原则**：
> 领域层必须保持零外部依赖。所有外部框架、库、基础设施都通过端口接口解耦。

**禁止事项**：
```java
// ❌ 禁止：领域层直接依赖 Spring Framework
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
private static final BCryptPasswordEncoder encoder = new BCryptPasswordEncoder(10);

// ❌ 禁止：领域层直接依赖 Redis 客户端
import redis.clients.jedis.Jedis;
private Jedis jedis = new Jedis("localhost");

// ❌ 禁止：领域层直接依赖 HTTP 客户端
import org.springframework.web.client.RestTemplate;
private RestTemplate restTemplate = new RestTemplate();
```

**正确做法**：
```java
// ✅ 正确：通过端口接口解耦
@DomainService
public class PasswordEncoderService {
    private final PasswordEncoderPort encoder;
    // 领域服务封装南向端口
}

// ✅ 正确：端口接口定义在 domain/port
public interface PasswordEncoderPort {
    String encode(String rawPassword);
    boolean matches(String rawPassword, String encodedPassword);
}

// ✅ 正确：适配器实现在 infrastructure
@Adapter(PortType.CLIENT)
public class BCryptPasswordEncoderAdapter implements PasswordEncoderPort {
    // 基础设施层实现
}
```

**识别需要解耦的依赖检查清单**：
- [ ] Spring Security（密码编码、认证）
- [ ] Spring Data（数据库操作）
- [ ] Redis（缓存、消息队列）
- [ ] HTTP 客户端（外部服务调用）
- [ ] 消息队列（Kafka、RabbitMQ）
- [ ] 文件存储（OSS、S3）
- [ ] 邮件/短信发送
- [ ] 第三方支付

## 三、应用层规范

### 3.1 应用服务（AppService）

**位置**：`application`

**命名规范**：`{Module}AppService.java`

**架构原则**：AppService 不应暴露领域模型给外部

| 返回类型 | 说明 |
|---------|------|
| DTO（Response） | 对外提供的数据 |
| 基本类型（Long/void/boolean） | 操作结果 |
| **领域模型** | ❌ 禁止对外暴露 |

```java
@Service
public class AdminUserManagementAppService {

    private final AdminUserRepository adminUserRepository;
    private final AdminUserMapper adminUserMapper;

    public AdminUserManagementAppService(
            AdminUserRepository adminUserRepository,
            AdminUserMapper adminUserMapper) {
        this.adminUserRepository = adminUserRepository;
        this.adminUserMapper = adminUserMapper;
    }

    /**
     * 查询管理员列表（分页）。
     */
    @Transactional(readOnly = true)
    public PageResponse<AdminUserResponse> findAll(AdminUserQuery query, Pageable pageable) {
        Specification<AdminUser> spec = ConditionSpecifications.fromAnnotation(query);
        Page<AdminUser> page = adminUserRepository.findAll(spec, pageable);

        return new PageResponse<>(
                adminUserMapper.convertList(page.getContent()),
                page.getTotalElements(),
                pageable.getPageNumber() + 1,
                pageable.getPageSize()
        );
    }

    /**
     * 查询管理员详情。
     */
    @Transactional(readOnly = true)
    public AdminUserResponse findById(Long id) {
        AdminUser adminUser = adminUserRepository.findById(id)
                .orElseThrow(() -> new ApplicationException(AdminMessage.ADMIN_NOT_FOUND));

        return adminUserMapper.convert(adminUser);
    }

    /**
     * 创建管理员。
     */
    @Transactional
    public Long create(CreateAdminUserCommand command) {
        Assertions.require(
                !adminUserRepository.existsByUsername(command.username()),
                AdminMessage.USERNAME_ALREADY_EXISTS
        );

        AdminUser adminUser = new AdminUser(command.username(), command.password(), command.nickname());
        AdminUser saved = adminUserRepository.save(adminUser);
        return saved.getId();
    }

    /**
     * 更新管理员。
     */
    @Transactional
    public void update(Long id, UpdateAdminUserCommand command) {
        AdminUser adminUser = adminUserRepository.findById(id)
                .orElseThrow(() -> new ApplicationException(AdminMessage.ADMIN_NOT_FOUND));

        // 业务逻辑...
        adminUserRepository.save(adminUser);
    }

    /**
     * 删除管理员。
     */
    @Transactional
    public void delete(Long id) {
        AdminUser adminUser = adminUserRepository.findById(id)
                .orElseThrow(() -> new ApplicationException(AdminMessage.ADMIN_NOT_FOUND));

        adminUserRepository.delete(adminUser);
    }
}
```

**应用服务规范要点**：

1. 使用 `@Service` 注解
2. 构造函数注入（禁止 `@Autowired` 字段注入）
3. 读操作用 `@Transactional(readOnly = true)`
4. 写操作用 `@Transactional`
5. **禁止暴露领域模型**：返回类型只能是 DTO、基本类型（Long/void/boolean）
6. 复杂领域逻辑考虑创建 DomainService（按需，非必须）

### 3.2 DTO 规范

**位置**：`application/dto`

**命令 DTO（写操作）**：`application/dto/command/{Action}{Entity}Command.java`

## 四、表现层规范

### 4.1 控制器（Controller）

**位置**：`web/controller`

**命名规范**：`{Entity}Controller.java`

```java
@RestController
@RequestMapping("/api/v1/{context}/{entities}")
@Validated
@Tag(name = "Admin Users", description = "管理员管理")
public class AdminUserController {

    private final AdminUserManagementAppService adminManagementAppService;

    public AdminUserController(AdminUserManagementAppService adminManagementAppService) {
        this.adminManagementAppService = adminManagementAppService;
    }

    @GetMapping
    @RequireAuth
    @RequirePermission(
        value = "admin:user:read",
        name = "平台管理 / 用户管理 / 查看",
        scope = "admin"
    )
    @Operation(summary = "查询管理员列表（分页）")
    public PageResponse<AdminUserResponse> findAll(
            AdminUserQuery query,
            @PageableDefault(size = 20) Pageable pageable) {
        return adminManagementAppService.findAll(query, pageable);
    }

    @PostMapping
    @RequireAuth
    @RequirePermission(
        value = "admin:user:write",
        name = "平台管理 / 用户管理 / 编辑",
        scope = "admin"
    )
    @Operation(summary = "创建管理员")
    public Long create(@Valid @RequestBody CreateAdminUserCommand command) {
        return adminManagementAppService.createAndReturnId(command);
    }
}
```

**控制器规范要点**：

1. 构造函数注入
2. 类级别加 `@Validated`
3. 权限注解：
   - `@RequireAuth`：需要登录
   - `@RequirePermission`：需要指定权限（`{context}:{module}:{action}` 格式）
4. 参数校验使用 `@Valid`
5. Swagger 注解：`@Tag`（类级别）、`@Operation`（方法级别）
6. 返回类型：`PageResponse<T>` 或具体 DTO/Long/void
7. URL 规范：`/api/v1/{context}/{resources}`

## 五、数据库规范

### 5.1 表命名规范

**格式**：`{context}_{table_name}`

- **context**：上下文名称的 3-4 个字母缩写（小写）
- **table_name**：蛇形命名（snake_case）

| 上下文 | 缩写 | 示例 |
|--------|------|------|

| account | `act` | `act_users`, `act_profiles` |
| tenant | `tnt` | `tnt_tenants`, `tnt_members` |
| course | `crs` | `crs_courses`, `crs_lessons` |
| platform | `plt` | `plt_users`, `plt_configs` |

### 5.2 迁移脚本规范

**位置**：`src/main/resources/db/migration`

**命名规范**：`V{version}__{description}.sql`

```sql
-- ========================================================================
-- {Context Name} Context: {Description}
-- ========================================================================

-- 主表
CREATE TABLE {prefix}_{table_name} (
    id              BIGINT PRIMARY KEY,
    name            VARCHAR(50) NOT NULL,
    -- 其他字段...
    created_at      TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    created_by      BIGINT,
    updated_by      BIGINT,
    deleted         BOOLEAN NOT NULL DEFAULT FALSE
);

-- 关联表
CREATE TABLE {prefix}_{relation_table} (
    parent_id       BIGINT NOT NULL,
    child_id        BIGINT NOT NULL,
    PRIMARY KEY (parent_id, child_id)
);

-- 索引（软删除过滤）
CREATE INDEX idx_{prefix}_{table}_{column} ON {prefix}_{table_name}({column}) WHERE deleted = FALSE;

-- 外键
ALTER TABLE {prefix}_{relation_table} ADD CONSTRAINT fk_{prefix}_{relation}_{parent}
    FOREIGN KEY (parent_id) REFERENCES {prefix}_{parent_table}(id);
```

**标准字段**：
- `id`：BIGINT 主键（TSID）
- `created_at`、`updated_at`：审计时间
- `created_by`、`updated_by`：审计人（BIGINT）
- `deleted`：软删除标记（BOOLEAN，默认 FALSE）

### 6.1 单元测试

**命名规范**：`{ClassName}Test.java`

**测试方法命名**：`given_{条件}_when_{操作}_then_{预期结果}`

```java
class AdminUserTest {

    @Test
    void given_valid_input_when_create_admin_then_success() {

    }
```

## 七、工具库使用规范（hutool）

### 7.1 集合初始化

**使用 hutool 替代 Java 标准库**：

| Java 标准库 | hutool 替代 |
|------------|-------------|
| `new HashSet<>()` | `CollUtil.newHashSet()` |
| `new ArrayList<>()` | `CollUtil.newArrayList()` |
| `new HashMap<>()` | `MapUtil.newHashMap()` |

```java
import cn.hutool.core.collection.CollUtil;
import cn.hutool.core.map.MapUtil;

// 推荐
Set<Long> roleIds = CollUtil.newHashSet();
List<AdminMenu> roots = CollUtil.newArrayList();
Map<Long, AdminMenu> menuMap = MapUtil.newHashMap();

// 不推荐
Set<Long> roleIds = new HashSet<>();
List<AdminMenu> roots = new ArrayList<>();
Map<Long, AdminMenu> menuMap = new HashMap<>();
```

### 7.2 Stream 收集操作

**Stream 操作仍使用 Java 标准库 Collectors**（hutool 不支持 Stream）：

```java
import java.util.stream.Collectors;

// Stream to List
List<String> names = users.stream()
    .map(User::getName)
    .collect(Collectors.toList());

// Stream to Set
Set<Long> ids = roles.stream()
    .map(AdminRole::getId)
    .collect(Collectors.toSet());
```

### 7.3 Java 语言特性保持不变

以下情况继续使用 Java 标准库：

| 场景 | 用法 | 说明 |
|------|------|------|
| 空不可变集合 | `List.of()` | Java 9+，性能最优 |
| Stream 终止操作 | `.toList()` | Java 16+，比 `Collectors.toList()` 更高效 |
| Optional | `Optional.ofNullable()` | Java 标准库 |
| Objects 工具 | `Objects.equals()` | Java 标准库 |

```java
// 推荐（Java 语言特性）
return List.of();  // 空不可变列表
return stream.toList();  // Java 16+ Stream 收集
return Optional.ofNullable(value);  // Optional 包装
if (Objects.equals(a, b)) { }  // null 安全比较
```
